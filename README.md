## How to Run

### Prerequisites
- OMNeT++ 6.3.0
- INET Framework 4.5
- Windows / Linux / macOS

### Setup Steps
1. Clone this repository:
```bash
git clone https://github.com/Zakihayder/NUCES-Campus-Network.git
```
2. Open **OMNeT++ IDE**
3. Click **File** → **Open Projects from File System**
4. Select the cloned folder → Click **Finish**
5. Right-click project → **Properties** → **Project References** → check **inet4.5**
6. Press **Ctrl+B** to build

### Running Simulations
- Right-click `simulations/omnetpp.ini` → **Run As** → **OMNeT++ Simulation**
- Select one of these configs:

| Config | Description |
|--------|-------------|
| `StaticRouting` | Custom C++ static routing (Member 1) |
| `RIP` | Dynamic distance-vector routing (Member 2) |
| `OSPF` | Dynamic link-state routing (Member 3) |

- Press **Ctrl+F** for fast simulation (recommended)
- Results saved in `simulations/results/`

## Failure Scenario
A critical link failure is simulated on the SE-to-Core backbone:

| Event | Time | Description |
|-------|------|-------------|
| Link DOWN | t = 60s | SE dept loses connectivity to core |
| Link UP | t = 120s | SE dept connectivity restored |

**Expected behavior:**
- **Static Routing** → Drops all SE traffic silently for 60 seconds. No recovery.
- **RIP** → Detects failure slowly via timers. Reconverges in ~30-180 seconds.
- **OSPF** → Detects failure via Hello mechanism. Reconverges in ~seconds.

## Traffic Generation
Traffic is generated by SE department hosts using **UdpBasicApp**:
- **Packet size:** 512 bytes
- **Send interval:** 10ms (100 packets/second per host)
- **Active window:** t=20s to t=155s
- **Destination:** App Server (10.0.6.1:5000)
